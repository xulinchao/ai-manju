# 分镜填写规范

当前执行规则见 [图片制作流程](图片制作流程.md)，本文件只定义镜头内容。

每行一个独立镜头：shot 唯一编号；act 所属段落；duration 为正数，表示计划素材时长；size 景别；vis 当前画面；first_prompt 起始静态画面；last_prompt 按需填写终点静态画面；h3_prompt 主要动作及运镜。图片阶段不要求模型未验证的精确时长。

叙事：narr 旁白、dialogue 台词、speaker 说话人、sfx 音效。导演：beat 节奏点、prev_end 本镜起始事实、next_goal 结束状态、axis 朝向与视线、anchor 空间地标、director 必要指令。

生成字段：image_route、references、edit_source、mask、crop、requires、scene_state、seed、style_override。格式见图片制作流程。不要把人物主参考或场景底图只写成文字而不绑定实际文件。

静态提示词只写当前瞬间；视频提示词写起点到终点的可见动作。每镜一个主要任务，复杂接触拆镜。结束状态每镜需要明确，但不强制每镜生成尾图。

mode 与图片路径独立：first 单图视频；reference 多参考视频；旧 firstlast 保留读取并警告语义。画幅取 project.json，不写死 4:3。不能因本轮去音轨就推断模型不具备声音或口型能力。

反打需要依据房间世界布局确定新构图，不能一律镜像翻转。人物身份与服装/印记等剧情状态分开；终点才发生的变化不要写进起始帧。

提示词写作规则统一见 [提示词规则库](提示词规则库.md)（Lira 图像 / ACTING 表演 / CINEDANCE 视频三套方法的引擎内蒸馏，全文在 references/ 目录）。不要强制每镜三分法、固定节拍数量或大量微动作，不把文字控制视为技术硬锁。
