# 画风与影视风格（权威定义 + 你现有体系覆盖对照）

> 用途：厘清「画风」和「影视风格」两个被长期混用的词，并按可执行维度拆开，方便找参考、写提示词、做内容。
> 核心结论：**画风管"一张画面长什么样"（静态）；影视风格管"观众如何经历这段时间"（动态）。二者正交，自由组合，各自都不混搭。**

---

## 〇、一句话正名

| 词 | 回答的问题 | 决定 |
|---|---|---|
| **画风** | 一张画面看起来是什么样 | 静态视觉（笔触/色彩/构图/线条） |
| **影视风格** | 画面怎样变化、故事怎样展开、声音怎样参与 | 动态视听（镜头/剪辑/叙事/声音/表演） |

> 「水彩」是一种画风，但「水彩动画」可以是温柔日常、悬疑故事、快节奏广告——同一种画风，能承载不同影视风格。

## 一、画风 = 三个子维度

### 1. 媒介 / 技法（用什么画，留下什么痕迹）

| 风格 | 视觉特征 | 用途 |
|---|---|---|
| 铅笔素描 | 灰度、排线、擦抹，重结构体积 | 人物、静物、草图 |
| 炭笔画 | 黑白反差大、粗犷笔触 | 肖像、情绪 |
| 钢笔画 | 线条明确、密集排线 | 建筑、旅行、书籍插图 |
| 线描 | 靠轮廓线条，少色彩明暗 | 人物造型、装饰图案 |
| 彩铅 | 细腻叠色、保留纸颗粒 | 动植物、手账、温柔插画 |
| **水彩** | 透明、晕染、渗透、自然水痕 | 旅行、童书、生活方式 |
| 水粉 | 不透明、色块厚实、覆盖强 | 静物、复古海报 |
| 油画 | 色层丰富、可厚涂可罩染 | 肖像、风景 |
| 丙烯 | 鲜明、覆盖力强、平涂或厚涂 | 壁画、抽象 |
| 粉彩/油画棒 | 颗粒、摩擦、涂抹感 | 儿童插画、表现性 |
| 马克笔 | 色面干净、笔触方向性 | 产品、服装、概念图 |
| **水墨写意** | 墨色浓淡干湿、笔势、留白 | 山水花鸟、东方意境 |
| **工笔** | 细勾线、层层设色、严谨 | 人物花鸟、传统题材 |
| 版画 | 刻痕、压印、套色 | 文学插图、强烈黑白 |
| 拼贴 | 照片纸张文字纹理组合 | 杂志、实验海报 |
| 喷绘/气笔 | 平滑渐变、柔边缘 | 复古商业、科幻 |
| 数字厚涂 | 数字笔刷塑体积材质光影 | 游戏原画、角色设定 |

### 2. 美术流派 / 审美传统（遵循什么审美原则）

| 风格 | 核心特征 |
|---|---|
| 写实主义 | 可观察的现实 |
| 超写实 | 极高精度，逼近/强化摄影 |
| 古典主义 | 秩序、比例、理想化 |
| 巴洛克 | 戏剧光影、动态、华丽 |
| 洛可可 | 轻盈细腻、柔和 |
| 浪漫主义 | 强烈情感、自然力量 |
| 印象主义 | 捕捉光色瞬间、笔触可见 |
| 后印象主义 | 强调结构、个人表达 |
| 野兽派 | 高饱和非自然色 |
| 表现主义 | 变形+色彩强化心理 |
| 立体主义 | 多视角重组 |
| 超现实主义 | 梦境逻辑、反常组合 |
| 抽象艺术 | 弱化对象、色线形表达 |
| 极简主义 | 减元素、比例空间重复 |
| 波普艺术 | 大众符号、鲜艳、复制 |
| 新艺术 | 植物曲线、流动轮廓 |
| 装饰艺术 | 几何、对称、放射、奢华 |

> 可混合：如「表现主义人物 + 数字厚涂」不矛盾——前者是审美，后者是技法。

## 二、影视风格 = 六个子维度

### 1. 制作形式

真人实拍 / 二维逐帧 / 二维骨骼·剪纸 / 三维动画 / 定格 / 转描 / 动态图形 / 混合媒介 / 屏幕叙事 / 档案拼贴

### 2. 摄影

观察式纪实 / 手持跟拍 / 稳定流畅 / 固定机位 / 长镜头 / 主观视角 / 旁观远景 / 特写主导 / 广角贴近 / 长焦观察 / 深焦群像 / 浅景深 / 对称构图 / 倾斜构图

### 3. 灯光·色彩·质感

### 4. 叙事·导演

古典叙事 / 生活流 / 社会现实主义 / 诗意叙事 / 慢电影 / 非线性 / 多线群像 / 极简叙事 / 超现实 / 魔幻现实主义 / 荒诞 / 黑色幽默 / 寓言式 / 元叙事 / 实验影像

### 5. 剪辑·节奏

### 6. 声音·表演

| 维度 | 风格 |

## 三、二者关系：正交，自由组合

```
画风（静态外观） × 影视风格（动态经历） = 完整视听语言
```

| 画风 | 影视手法 | 效果 |
|---|---|---|
| 水彩 | 缓慢镜头+自然声+日常 | 温柔细腻 |
| 水彩 | 跳切+异常声+梦境 | 脆弱诡异 |
| 工笔 | 对称+缓慢调度+克制表演 | 精致庄重 |
| 水墨 | 留白+长镜头+稀疏声 | 空灵诗意 |
| 美式漫画 | 快速剪辑+夸张动作 | 冲击力 |
| 黏土 | 固定机位+冷面+突发 | 荒诞黑色幽默 |
| 像素 | 长时间停留+环境声 | 孤独怀旧 |
| 写实三维 | 流畅运镜+精细灯光 | 精致商业感 |
| 拼贴 | 档案旁白+联想蒙太奇 | 散文影像 |

> 这解释了"为什么生成图好看、视频却没感觉"：只指定了美术外观，没指定动作/镜头/时间/声音。

## 四、你现有 skill 的覆盖盲区（诚实对照）

| 层级 | 该管的事 | 你的 skill | 覆盖 |
|---|---|---|---|
| 画风·媒介技法 | 用什么画 | 无 | ❌ 盲区 |
| 画风·美术流派 | 什么审美 | 无 | ❌ 盲区 |
| 画风·视觉母题 | 什么世界观 | 无 | ❌ 盲区 |
| 影视·制作形式 | 怎么拍 | 无（默认生图） | ⚠️ 半覆盖 |
| 影视·摄影 | 机位运镜 | **CINEDANCE** | ✅ |
| 影视·灯光色彩 | 光调 | **Lira**（间接） | ⚠️ 半覆盖 |
| 影视·叙事导演 | 怎么讲 | **CINEDANCE** | ✅ |
| 影视·剪辑节奏 | 怎么切 | **CINEDANCE**（节拍） | ⚠️ 半覆盖 |
| 影视·表演 | 怎么演 | **ACTING 7** | ✅ |
| 影视·声音 | 声音设计 | 无 | ❌ 盲区 |

**结论**：
- ✅ 已覆盖 = 调度三件套（摄影 / 叙事 / 表演）
- ❌ 盲区 = 画风三件套（媒介 / 流派 / 母题）+ 声音

**画风"难定"是结构性的**——体系里没有任何环节负责它。解法不是再学画风，而是把画风变成"显式的一层设定 + 有约束的决策流程"（见 style-decider skill）。

## 五、三层结构：统一视觉的落地方法

### 三层

| 层级 | 写什么 | 用在哪 |
|---|---|---|
| **全片视觉设定** | 画法、角色造型、材质、色彩、光线、时代环境 | 所有图+视频共用 |
| **单镜头画面设定** | 人物、场景、景别、构图、姿态、道具位置 | 首帧/尾帧/生图 |
| **单镜头动态设定** | 动作过程、镜头运动、速度、先后、结束态 | 图生视频/首尾帧/文生视频 |

> 全片设定管"始终长什么样"；画面设定管"这一刻"；动态设定管"接下来怎么变"。

【动态基调】

## 六、模糊词 → 可见特征 拆解表

| 模糊描述 | 更容易执行的描述 |
|---|---|
| 电影感 | 侧面中景、前景遮挡、窗侧柔光、背景分层 |
| 文艺片风格 | 固定机位、生活化动作、较长停留、环境声主导 |
| 高级感 | 限定色板、材质统一、构图简洁、光向明确 |
| 梦幻感 | 柔和扩散光、朦胧边缘、缓慢漂浮运动 |
| 紧张感 | 狭窄构图、人物停顿、镜头逼近、细微声 |

## 七、真正要统一的五项（不止风格词）

1. **画面风格**：线条、材质、细节程度、色板
2. **角色身份**：脸型、发型、体型、服装、标志配饰
3. **场景空间**：门窗方向、家具位置、道具关系
4. **光线逻辑**：光从哪来、时间、天气、曝光、色温
5. **动作连续性**：上镜结束姿态能否接上下镜

> 只复制"水彩动画风"只能统一第 1 项；其余 4 项靠参考图、场景设定、镜头衔接。

> 视觉统一 ≠ 每镜完全一样。景别/角度/构图可变，但人物身份、美术规则、空间关系必须对得上。

## 附：三种生成方式的提示词写法

### A. 图生视频（先生成图）
- 生图：视觉设定 + 角色设定 + 镜头画面（写全）
- 视频：输入图 + 镜头动态 + 简短视觉保持要求（可短，因图已提供大量信息）

### B. 首尾帧视频
- 首尾帧共用设定，只改"这个镜头真正要变的部分"
- 尾帧优先基于首帧编辑或用参考图约束，不要单独重生成
- 首尾帧差异越大，模型补的内容越多；跨场景建议拆多镜

### C. 文生视频
- 视觉设定 + 角色设定 + 镜头画面 + 镜头动态（合并写全）
- 工具不生成声音时，声音留后期配音/音效

## 附录：概念三区分（题材 / 类型 / 风格）

| 概念 | 回答 | 例子 |
|---|---|---|
| 题材 | 讲什么内容 | 校园、家庭、太空 |
| 类型 | 什么故事模式 | 爱情、悬疑、恐怖、喜剧、动作 |
| 风格 | 什么方式呈现 | 手持纪实、对称、黑白、诗意叙事 |

> 例：题材=搬到陌生城市；类型=爱情；画风=铅笔+淡彩水彩；影视=固定机位+生活流+缓慢剪辑+环境声。
