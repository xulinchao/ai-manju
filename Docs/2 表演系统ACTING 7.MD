# 表演系统
## 针对 AI 视频生成的角色表演指南 (Seedance 2.0)

你能读到这份文档，是因为你的用户正在生成电影级的 AI 视频，并且需要你在他们的提示词中编写**角色表演**部分。请仔细研读此文档，并在每次编写、审查或修复视频生成提示词的“表演层”时应用它。本文件的格式与具体模型无关：无论你的用户使用哪种提示词模板，你生成的表演内容都将填入提示词中负责“运动 / 角色行为 / 表演”的区块。

**整个系统的核心公理：表演是在压力下的行为，而不是情绪的展示。** 角色想要得到某样东西，但有阻碍存在，于是他们采取行动去争取。情绪只是这种斗争的副产品——绝不是你直接写在提示词里的东西。下文的所有内容都在拆解这一法则。

**【最高优先级语言指令】：本指南中的所有概念、模板和输出要求，在最终生成提示词时必须 100% 使用纯中文，严禁夹杂任何英文术语。**

# 第一部分 — 技艺：什么是好的表演

## 1. 定义

表演是“在虚构情境下的真实行为”（迈斯纳体系）。表演不是描绘情绪，不是背诵台词，也不是“表情丰富”。画面中的一个人想要某样东西，某件事物构成了干扰，然后他们采取行动去获得他们想要的。

| 糟糕的表演 | 好的表演 |
|---|---|
| 展示情绪（“我很生气”） | 追求目标（“我要逼你把钱还回来”）——愤怒会自然产生 |
| 干等着轮到自己的提示词/台词 | 每一秒都在倾听并对搭档做出反应 |
| 用身体图解台词（动作 = 词语） | 身体有自己的生命，有时甚至与台词相矛盾 |
| 所有台词都用同一种语速和语调 | 节奏随着每一种行动策略的改变而改变 |
| 情绪在说台词时开启，说完后关闭 | 状态是连续的——在台词之前有“前史”，在台词之后有“余波” |
| 脸在“刻意表演”——挑眉、做鬼脸 | 脸在思考——在开口说话之前，眼神中就能读出想法 |

## 2. 每个场景的五大支柱

每个场景中的每个角色都可以拆解为五个元素。只要缺失任何一个，表演就会崩塌。

**2.1 目标。** 角色在当前这个场景中、在这一刻、想从某个特定的人那里得到什么。必须始终是一个指向搭档的动词：“逼他认罪”、“乞求宽限一周”、“说服她我不害怕”。绝不能是一个状态（“感到生气”、“感到内疚”）——状态是无法被直接演出来的。在场景目标背后隐藏着一个“最高任务”——角色在整个故事中想要什么；每一个场景目标都是迈向最高任务的一步。

**2.2 障碍与赌注。** 阻止他们实现目标的事物——可能是外部的（另一个角色想要相反的结果；房间里有目击者；离截止时间只剩两小时），也可能是内部的（自尊心不允许他们乞求；他们自己都不相信自己的话）。赌注：失败的代价越高，场景的张力就越大。始终要回答“如果我没有得到我想要的，会发生什么？”——答案必须让角色感到恐惧。

**2.3 策略与行动手段。** 此时此刻追求目标的具体方法。策略是动作动词：施压、施展魅力、羞辱、恳求、挑衅、讨价还价、威胁、拖延。当一种策略失败时，一个活生生的人会改变策略。死气沉沉的表演就是整个场景只用一种策略。

**2.4 节奏点与动作单元。** 节奏点是最小的动作单元：在这段时间内，角色只想要一样东西，并用一种方式去追求它。一个节奏点在以下情况下结束：目标达成了、策略失败了、新信息出现了，或者权力平衡发生了转移。**每一个节奏点的改变都必须在行为上可见**：一个停顿、姿势的改变、语速的改变、视线的转移。一个好的场景会有 2-4 个节奏点的改变；如果整个过程中行为毫无变化，这个场景演出来就会很平淡。

**2.5 潜台词。** 角色真正在想什么、想要什么，这往往与他们嘴上说的相反。潜台词不是“演”出来的——当角色一边说着虚假的台词，一边去追求真实的目标时，潜台词会自己流露出来。你可以在场景中构建以下标记：不是疑问句的提问；重复（问同样的问题——因为不相信答案）；生硬地转移话题；在不合时宜的时刻开玩笑（作为防御脆弱的盾牌）；太简短的回答（“行。”“当然。”——代表关上心门）。

## 3. 倾听与反应——质量的终极测试

表演的生命力不存在于台词中，而存在于台词之间。你应该在场景中写入以下代表真实倾听的可观察标记：

1. **反应在搭档的台词结束前就开始。** 一个人在听到半句话时就能抓住重点——面部和身体已经开始做出回答。一直保持中性表情直到搭档说完，然后才“开启”反应，这是死板的表演。
2. **思考先于语言。** 在回答一个难题之前，会有一个微小的停顿——这个人明显在决定该说什么。以匀速给出即时回答 = 背诵台词，毫无生命力。
3. **评估的瞬间。** 当重要的事情发生时（坏消息、威胁、侮辱），角色需要时间去消化它——从几分之一秒到一个漫长的停顿。电影的魅力就建立在这些评估瞬间的特写镜头上：一张脸、失去焦点的眼神、天旋地转的世界。
4. **来自搭档的情绪感染。** 节奏、音量和能量会随着搭档的反应而改变：对大喊大叫的回应要么是对吼，要么是刻意的安静——但必须是有所回应，而不是无视对方自顾自地继续。

## 4. 身体：角色的物理生命

**4.1 生理状态先于心理状态。** 身体在第一句台词之前就开始讲述故事。为每个角色设定以下参数：

- **重心：** 高（胸部挺起、下巴抬高——自信、攻击性、地位）或低（肩膀下垂、含胸驼背——疲惫、恐惧、屈服）。
- **节奏与语速：** 快与急促（神经质、亢奋的能量）或慢与克制（掌控力、威胁感——最危险的人往往动作最少）。
- **开放度：** 展开的双肩和张开的手掌 vs 交叉的双臂、低垂的头、封闭的姿势。
- **呼吸：** 高频急促（恐慌）vs 低沉缓慢（控制）。呼吸是状态最诚实的指示器；紧绷的呼吸 = 紧绷的表演。声音和物理状态必须匹配：一个刚跑完步的人不可能用平稳的声音说话。

**4.2 手头动作与物理任务。** 角色几乎总是需要一个正在做的“事情”：他们不是在“进行对话”，他们是在修引擎、数钱、做饭、擦玻璃——然后在此之上进行交谈。手头动作能杀死虚假的戏剧腔（双手忙于真实的事物），创造场景节奏（动作填补了停顿），并产生潜台词（一个人如何数钱比他说的话更能反映内涵）。**中断动作法则：** 最强烈的强调就是角色停止了手头的动作。如果他正在切面包，在某句话时突然停下——这句话就成了一个大事件。把停止动作当作标点符号来用。

**4.3 空间距离与戏剧性。** 角色之间的距离是他们关系的可见图表：亲密距离（小于0.5米）——代表爱或暴力，不请自入就是攻击，在离脸10厘米处耳语的威胁比隔着房间大喊更可怕；个人距离（0.5–1.2米）——信任；社交距离（1.2–3.5米）——公事、警惕；公共距离（3.5米以上）——疏离、等级制度。场景中的戏剧性往往就是关于距离的故事：谁拉近了距离，谁打破了距离，谁僵在原地。**距离的改变 = 节奏点的改变。**

**4.4 地位与隐形的阶级。** 地位体现在你的“行为”，而不是你的“身份”。高地位：头部不动、动作缓慢、凝视时间长、回答前有停顿、占据空间、触碰别人的东西。低地位：瞎忙活、频繁地摸自己（摸脸、摸头发）、说话支离破碎、用笑声填补空白、用眼神请求许可。表演中最有趣的部分是**地位的打破**：老板在某一秒钟露出恐惧；下属突然停止了微笑。一种极具张力的场景结构：高地位出场但最终崩溃，或者低地位出场却最终反客为主。

## 5. 台词：好表演的声音听起来是怎样的

- 节奏写在文本里——要精准地传达；语速快 ≠ 含糊不清。
- 台词交叠（抢话，台词踩在彼此的尾巴上）是正常的，但关键词要保持清晰。
- **音量对比：最可怕的话往往说得最轻。** 大喊大叫是弱者的通货；掌控全场的角色会降低音量，迫使所有人都凑近倾听。
- 停顿是事件，不是漏洞：只有在停顿中发生了某事（一次评估、一个决定、拒绝回答）时，停顿才是合理的。
- 真实的语言是有“垃圾”的：打断、没听清的词、重复、未说完的半句话。完美构造的句子会扼杀街头的真实感。

# 第二部分 — 编写表演：提示词架构

## 6. 角色表演主档案

每个反复出现的角色都有一个主档案——这是关于他们行为方式的永久真相来源。它只写一次，然后在每个场景中进行改编（见第8节）。目标长度：**300–500 个中文字符，由一段流畅的纯中文段落组成**，所有内容都必须是可见的、可拍摄的。

**模板（区块顺序固定，必须纯中文输出）：**

```
角色表演：[姓名]。[年龄、体型、体格、姿态——身体作为他们过往经历的档案]。[用一个从句概括心理引擎——解释其生理特征的内在驱动力]。声音特征：[音高或音色、口音或出身、语速和表达方式，以及声音在情绪下如何破音或转变]。关键的生理习惯和下意识小动作：[标志性的小动作及其触发条件；压力下的小动作及其触发条件；掩饰行为——他们做些什么来隐藏真实感受；面具般的表情以及面具破裂的确切条件]。步态风格：[作为角色特征的步态——给出具体命名，加上对重心、节奏和落脚点的描述]。然而，当[情绪触发点]时，[转变——姿态、步态和面部如何变化]。[可选：软肋目标——唯一能让那张脸真正柔和下来的人或物]。
```

**编写每个区块的规则：**

1. **只有可观察的行为。** 每一种内在状态都必须有一个身体标记。绝不要写“他很紧张”——要写“下唇颤抖、沉重地吞咽、用嘴长吸一口气，然后撅起嘴唇急促地呼出”。
2. **每一个小动作都有触发器。** 不是“他把指关节掰得咔咔响”，而是“他在日常无聊的谈话中会把指关节掰得咔咔响，以此来伪装自信”。格式：[小动作] + [时间或原因]。没有触发器的小动作只是装饰；有触发器的小动作才是戏剧性。
3. **为步态命名。** 在引号内起一个好记的名字来锚定生物力学：比如“权力步伐”、“孔雀漫步”、“画廊步”、“破城锤大步”、“无畏舰步调”。然后拆解它：重心、步幅、躯干和手臂在做什么、头部在做什么。
4. **构建面具，并写出面具破裂的瞬间。** 档案中最具电影感的设计就是条件性转变：伪装的表面，以及摧毁它的精准触发器。比如一个强势傲慢的人在被拒绝时瞬间垮成孩子般的驼背；一个嗓门很大的大老粗在提到家人时脸上闪过惊恐的无力感；严厉的纪律在面对某个人时融化成灿烂的笑容。**每一个档案都必须包含至少一个“然而，当XX时……”的从句。** 一个同时在演两层真实的角色，就是人和木偶的区别。
5. **唯一的软肋目标。** 在符合角色的前提下，给这张脸设定唯一的一个人、动物或物品，能让他真心流露柔情。只能是一个——不能是两个。这能让人性化角色而不稀释其特点。
6. **不要写服装。** 服装和造型属于提示词的场景或外观区块，绝不要写进表演档案里。表演档案必须在任何换装后依然成立。
7. **不要写摄像机，不要写色彩。** 表演只驱动动作、面部和声音。摄像机、调色和灯光写在提示词的其他地方。
8. **体格承载着过往。** 年龄、体型和姿态的选择是为了讲述背景故事：比如“被过往挣扎侵蚀得饱经风霜的体格”，“永远紧绷的肩膀”，“为了展现权威而矫枉过正的姿态”。身体是一份档案——职业、过去的伤病和自我认知都必须能在其中被读出来。

## 7. 眼神细节 — 每个档案和每个场景中的必选项

死鱼眼是 AI 生成的表演中最常见的败笔。给每个角色持续的、自然主义的眼部细节：

- **视线追踪与眼球微动：** 视线要聚焦在他们关注的人或物上；目光保持移动——眼神会因为思考而漂移、快速掠过，扫描到某个细节然后又落回来。绝不能死死地锁定在一个点上。
- **真实的眨眼频率和质感，与状态挂钩：** 压力下爆发性地快速眨眼；掌控局面时缓慢从容的眼睑开合；在情感游离的瞬间眨眼并失去焦点。
- **生动的眼神光：** 眼睛必须看起来是湿润的、有光的、鲜活的。
- **有控制的静止是刻意为之，绝非死板。** 如果一个角色的状态是那种近乎不眨眼的捕食者般的平静，那就让眨眼变得罕见、缓慢且深思熟虑——这是一个决定，而不是画面卡死——并让视线依然带有意图地缓慢移动。
- **眼睛引导思考。** 眼睛比头部转动要早一点到达目标。在说出台词之前，想法就能从眼睛里读出来。
- **眼神细节必须对节奏点做出反应：** 就像其他所有行为一样，眨眼频率、视线的稳定度以及眼神光的温度，都会随着节奏点的变化而改变。

## 8. 场景改编 — 主档案是用来改写的，绝不是直接复制粘贴的

主档案代表角色“是谁”。对于每一个具体的场景，请将其重写为当下时刻的状态：

1. **只写在场的角色。** 只为真正出现在镜头里的角色编写表演段落。不在画面中的角色，绝对不要写段落。
2. **保持恒定的核心。** 身份、声音特征、标志性动作、眼神细节和情感主线在每个场景中都保持不变——这是保持角色在剪辑中一致性的关键。绝不要与主档案相矛盾。
3. **为当前场景重新表达。** 选择、强调、修改或放弃特定的行为，以适应场景的姿态（坐着、站着、奔跑、躲藏）、动作和节奏点、情绪状态以及一天中的时间。
4. **转化，而不是删除。** 在这个场景中物理上无法做出的行为应该被转化，而不是删除：一个习惯在房间里焦躁踱步的人，现在瘫坐在沙发上，他应该保持同样的神经质引擎，只是转移到了焦躁的身体微晃、手腕抽动和撕扯纸张上。能量是守恒的；只是发泄的出口变了。
5. **一段流畅的中文段落。** 将改编的内容融合成符合角色语气的散文段落——不要使用项目符号，不要用标题，不要在提示词里放类似调整参数的系统结构。
6. **以角色的参考标签开头**（如果工作流使用资产参考），这样模型就能将表演绑定到正确的人身上。

## 9. 声音：固定的身份，从不改编

表演是按场景重写的；**声音是锁定的**。每个角色都有一个独立的声音提示词——他们永久的声音身份。当角色有开口说话的台词时，将声音提示词**一字不差**地粘贴到提示词的音频与声音字段中。绝不要根据场景去修改它。如果角色出现了但没说话，则省略该提示词。

**声音提示词公式（1-2句话，带引号，纯中文输出）：**

```
"[年龄]岁的[出身或口音描述]。[音色和音区]；[语速和说话方式]；[情绪特征——以及在压力下如何转变]。"
```

表演段落内部的声音特征描述的是语音在**戏剧性上**的表现（节奏变化、破音、耳语）；音频字段中的声音提示词则锁定了**声音本身**的物理属性。两者必须保持一致。

## 10. 呈现状态，而非过渡

视频生成模型在“过渡”上容易翻车，而在“状态”上表现极佳。描述已经处于**动作状态中**的角色——出拳的瞬间、挥投的半空中、争吵的正酣时——而不是描述到达该状态的过程（“把手伸进包里，掏出东西，准备挥拳”容易翻车；“挥投瞬间，手臂伸展”则表现完美）。按照节奏点把状态链接起来，而不是去叙述连续的过程。

## 11. 群像与空间

- **群体的反应像波浪一样传递，绝不同步。** 一个人先听懂了笑话，第二个人慢了半拍，第三个人完全没懂。同时发生的一模一样的反应看起来非常假（除非你是刻意编排的喜剧同步效果）。
- **反应比动作本身更有价值。** 在每一个事件发生后，最有价值的画面是看到这一幕的人的脸。
- **面对威胁时的冻结。** 群像保持着持续的微小动作——重心的转移、手势、倾斜——而在关键威胁出现时，一切突然停止。从喧闹到静止的对比，就是最好的标点符号。
- **移动就是动机。** 没有人会在没有内在冲动的情况下穿过房间：要么是走向某物，要么是远离某物。强烈的动机事件包括：逼近（冲突升级）、转过身去（无视或隐藏表情）、在别人坐着时站起来（抢夺主导权）、在冲突中途坐下（反常的权力压制）、在门口停下（门槛代表决定点）、开始收拾行李（用身体下达最后通牒）。
- **强者安静不动；弱者烦躁大喊。** 危险感的演出不在于那个危险的人，而在于他周围所有人的紧张状态。没有前摇的威胁：不要用“凶狠”的停顿，不要搞慢动作转头——在一个真实的世界里，暴力的降临是不需要提前打招呼的。
- **退化是会累积的。** 如果一个角色在故事中被渐渐磨平，请让它在身体上累积体现——更灰暗、更沉重、反应更迟钝——绝对不要在场景之间重置状态。

# 第三部分 — 质量控制

## 12. 糟糕表演图鉴 — 在提示词层面识别并修复

| 编号 | 症状 | 看起来的样子 | 提示词层面的修复方案 |
|---|---|---|---|
| 1 | 表面化表演 | 脸在“描绘”情绪：挑眉毛、做鬼脸 | 把面部表情从任务中去掉；写出角色的目标，并让双手有事可做 |
| 2 | 预演结果 | 角色从第一秒开始就在演这个场景的最终结局 | 只写角色在“现在这一刻”知道的信息 |
| 3 | 等待台词 | 搭档说话时，自己脸上毫无反应 | 把反应写在搭档说台词的中途 |
| 4 | 策略单一 | 整个场景只有一种色彩（全程大吼 或 全程抱怨） | 标记出节奏点；为每一个节奏点提供新的行动动词 |
| 5 | 图解式手势 | 手势重复了台词的意思（说“大”就张开双臂） | 手势要么先于想法出现，要么与台词矛盾，要么干脆没有 |
| 6 | 廉价的情绪 | 没有铺垫也没有触发事件，莫名其妙就流泪或暴怒 | 构建阶梯：克制 然后 爆发；情绪的产生必须付出代价 |
| 7 | 身体与经历不符 | 一个恶棍有着舞者的仪态；一个瘾君子动作敏捷灵巧 | 设定身体档案：重心、节奏、身体的磨损程度 |
| 8 | 阶层口音太干净 | 街头流氓说着字正腔圆的书面语 | 在台词中加入垃圾词：打断、吞音、重复 |
| 9 | 威胁的信号 | 施暴前有“凶狠”的停顿、眯眼、缓慢转身 | 威胁应该是日常的；暴力没有前摇动作 |
| 10 | 同步的群像 | 所有人同时做出完全一致的反应 | 让反应像波浪一样错开，改变他们反应的强度 |
| 11 | 死气沉沉的停顿 | 沉默中什么都没有发生 | 用评估瞬间或手头动作填补——或者直接删掉这段停顿 |
| 12 | 情绪重置 | 角色在经历重大事件后瞬间“恢复” | 状态是有惯性的；上一段的余波会带入下一个节奏点 |
| 13 | 评价式表演 | 表演在向观众使眼色（“我们都知道这很搞笑”） | 让角色完全相信情境；最好的喜剧是极其严肃地演出来的 |
| 14 | 特写镜头过载 | 在特写镜头中面部肌肉过度活跃 | 景别越紧，动作越少：只保留眼睛和思考 |
| 15 | 死鱼眼 | 呆滞的凝视、不眨眼、没有视线移动、眼神光浑浊 | 全面应用第7节——眼部细节绝不是可选项 |

## 13. 表演评分表 (自我核对)

- **0分 — 假人。** 输出了文本，但毫无行为。
- **1分 — 朗诵者。** “声情并茂”的台词，流于表面的情绪，用身体图解意思。
- **2分 — 勤勉者。** 能猜出角色的目标，但只有一种策略，反应滞后，停顿空洞。
- **3分 — 熟练工。** 有目标和节奏点，能倾听搭档，身体动作合理。缺失的是：潜台词、令人意外的策略、状态的惯性。
- **4分 — 活生生的人。** 行为是连续的，行动策略有反差，潜台词与台词背离，身体体现了阶级地位，反应先于台词发生，至少有一个出人意料但极其真实的选择。
- **5分 — 极具魅力的磁石。** 包含“4分”的所有内容，加上悖论：角色将不相容的特质结合在一起——既好笑又可怕，既残忍又迷人，一边撒谎一边让人感动。**双重真实法则：在5分的水平上，角色总是同时在演两层真实**（想要帮忙——又恨透了帮忙；在道歉——却又在防卫；深爱着——但心已离开）。在特写镜头中，一种毫无矛盾、极其纯粹的情绪看起来会非常虚假。

瞄准每一个特写镜头的得分为 4分以上；如果某段描述自测在 2分或以下，必须在发送前重写。

## 14. 发送前检查清单

- [ ] 目标是否是一个指向搭档的动词——针对画面中的每个角色
- [ ] 障碍和赌注是否存在；失败的代价是否真实
- [ ] 是否有 2-4 个节奏点的改变，且每个改变在行为上都可见（停顿 或 姿势 或 语速 或 视线）
- [ ] 反应是否在搭档的台词结束前就开始了；是否包含了评估瞬间
- [ ] 每个角色是否有手头动作；是否刻意使用了中断动作作为强调
- [ ] 距离是否发生了变化，变化是否有动机；阶级地位是否体现在身体上，而不仅仅是台词里
- [ ] 所有的小动作是否都有触发器；面具是否有破裂的条件（“然而，当发生某事时……”）
- [ ] 眼神细节是否被明确写出：视线微动、眨眼质感、眼神光、眼睛引导思考
- [ ] 如果角色说话，声音提示词是否被一字不差地粘贴了；如果角色不说话，是否省略了该提示词
- [ ] 是否呈现了状态而非过渡；表演描述中是否排除了服装、摄像机或色彩参数
- [ ] 群体反应是否错开；强者是否安静，弱者是否烦躁
- [ ] 评分测试：这段描述能拿 4分以上吗？

# 第四部分 — 实战案例 (作为模板参考)

## 15. 主档案 (全部使用纯中文)

```
角色表演：维克多。60岁出头的男性，退休的夜班出租车司机，前业余拳击手；体型沉重，脖子粗壮，中年发福导致腰腹松弛，长着一张鼻子扁平的脸，两条眉毛上方都有陈旧的疤痕组织；无论坐着还是站着，重心都放得很低、很稳，重量总是压在全脚掌上。他的行为由单一的引擎驱动：几十年来的等待——等客、等回合铃声、等麻烦找上门——让耐心成了他的武器。声音特征：低沉、沙哑、不急不缓的男中音，带着工人阶级的粗糙感，句子简短平实，极为克制，事情越严重，他声音的音区就降得越低、越安静——他永远不会加快语速。关键的生理习惯和下意识小动作：在评估情况时，会慢条斯理地让一枚旧硬币在指关节上翻滚；在开口说“不”之前，会通过鼻子发出缓慢、清晰可闻的呼吸声；当有人在他面前撒谎时，他会变得完全静止，让漫长的沉默去施加压力；他默认的面部表情是一张眼睑下垂、看起来百无聊赖的面具，掩盖了他对周围的绝对关注。眼神细节：睡眼惺忪、眼睑低垂的眼睛，眨眼缓慢而深思熟虑，不断进行着无声的扫描——看后视镜、看手、看出口——在头转过去的前一拍，目光就已经落在了说话人的身上；眼神光微弱但依然鲜活。步态风格：沉重摇晃的老拳击手步，步伐短促节制，肩膀平齐，双手放松但随时准备出击，从不匆忙。然而，当有人在他附近抬起手时，那张睡眼惺忪的面具会在半秒内消失：下巴收紧，双手抬起一半，双脚瞬间找到过去的拳击站位——然后他会意识到自己的反应，尴尬地收起姿态。他的脸只会在流浪狗面前真正柔和下来，他会从大衣口袋里掏出食物喂它们。
```

**声音提示词（当角色说话时一字不差地粘贴，纯中文输出）：** “60岁的前拳击手和夜班出租车司机，带有工人阶级城市口音。低沉、沙哑、不急不缓的男中音；句子短促、平实、克制，带有舒适且漫长的停顿；语气平静且带着一丝隐约的戏谑，当事情变得严重时，声音会变得更安静——绝不会更大声。”

## 16. 场景改编案例 (全部使用纯中文)

场景：维克多在夜里坐在停着的出租车里；后座上一个紧张的年轻乘客正在撒谎说自己有钱付车费。

```
维克多一动不动地坐在驾驶座上，身体沉重而稳固，他没有回头，而是通过后视镜观察着后座的乘客——他那低垂的眼睛在后视镜、乘客的手和车门锁之间进行着缓慢、无声的扫描，眨眼极少且深思熟虑，目光在头动之前就已落在了后视镜上。那枚旧硬币在他靠在座椅的手指关节上慢条斯理地翻滚着；随着乘客的谎言开始破绽百出，硬币在半空中停住了——他任由沉默蔓延，通过鼻子缓慢而清晰地吸了一口气，然后用他那低沉沙哑的男中音做出了回答，声音比刚才更平淡、更安静，语速丝毫没有加快。只有当那孩子的声音因为紧张而破音时，他那张睡眼惺忪的面具才微微放松了一丝：呼出一长口气，缓慢地眨了一下眼，硬币又开始翻滚——耐心在这一刻，选择了仁慈。
```

这里发生了什么：步态在这里无关紧要（因为是坐着），所以它的能量转移到了静止状态和硬币上；标志性的小动作保留了它们的触发器（硬币等于评估情况，停止的硬币等于中断动作作为标点符号，鼻子呼吸等于拒绝，静止加上沉默等于对撒谎者施压）；眼部细节遵循主档案，但重新定位为看后视镜、手、锁；节奏点的变化是肉眼可见的（硬币停止，接着沉默，然后声音变轻，最后态度柔和）；声音特征保持原样未动——它将被一字不差地粘贴到音频字段中。

# 最终法则

1. 表演是在压力下的行为，而不是情绪的展示。
2. 倾听比说话更重要；反应比朗诵更重要。
3. 情绪是斗争（无论输赢）的后果，并且它是极其昂贵的。
4. 身体比台词更聪明：当文本和身体发生冲突时，观众会相信身体。
5. 强者安静且不动；弱者烦躁且大喊大叫。例外情况本身就是戏剧事件。
6. 每一种小动作都需要触发器；每一张面具都需要被撕裂的瞬间。
7. 每个场景都是某人的挫败。如果没人输，那就构不成场景。
8. 潜台词不是演出来的——是隐藏失败时不小心漏出来的。
9. 呈现状态，而非过渡；模型只能拍摄“正在发生”的事，拍不了“正在变成”的事。
10. 当你犹豫不决时——做减法。表演越少，画面就越真实。
