# AI 视频画风与影视风格实用手册

> 适用场景：先生成图片再做视频、首尾帧视频、直接文生视频。本文是一套创作与生产组织方法，不是唯一的学术分类，也不依赖某个生成模型。

**核心原则：一套全片视觉规则，多份镜头画面与动态描述。图片与视频分工描述，共用视觉设定。**

## 1. 先把三个概念分清

| 概念 | 主要回答 | 包含什么 |
|---|---|---|
| 画风／视觉风格 | 画面呈现出什么外观？ | 造型、线条、笔触、材质、色彩、明暗、空间表现 |
| 影视风格 | 作品怎样通过影像与声音组织观看体验？ | 美术、摄影、场面调度、表演、时间、剪辑、叙事、声音 |
| 生成方式 | 用什么输入与工具生产镜头？ | 文生图、图生视频、首尾帧视频、文生视频、后期合成 |

**画风与影视风格有重叠，不是完全独立的两条轴。** 色彩、光线、构图和材质同时作用于静态画面与动态影像。影视风格的范围更广，还包含这些视觉特征如何随时间变化、如何与叙事和声音共同起作用。

“画风管静态，影视风格管动态”适合作为入门记忆，但不宜当作严格定义。一个静帧也能体现电影的美术与摄影风格，只是无法独自表达完整的剪辑、动作和声音。

两者可以组合，也可以有计划地混合。关键是明确主次、作用范围和一致性规则。例如“木刻感轮廓＋淡彩水墨上色”有明确分工；“纯平面水墨＋照片级皮肤毛孔＋厚重三维塑料材质”若同时作用于同一个人物表面，就容易产生冲突。

### 题材、类型、情绪和风格也要分开

| 维度 | 例子 | 创作作用 |
|---|---|---|
| 题材 | 张天师役鬼、校园生活、太空探索 | 确定讲什么 |
| 类型 | 民间志怪、悬疑、喜剧、爱情 | 确定故事模式与观看期待 |
| 情绪 | 温暖、不安、孤独、庄重 | 确定希望观众感受到什么 |
| 视觉风格 | 淡彩水墨、扁平色块、写实三维 | 确定画面外观 |
| 视听手法 | 固定机位、低声旁白、反应镜头、环境声 | 把故事与情绪具体呈现出来 |

“悬疑”不会自动决定颜色，“水彩”也不会自动意味着温柔。相同画风可以通过不同动作、剪辑和声音呈现不同情绪。

## 2. 统一风格的四层结构

### 第一层：全片视觉规则

规定全片共同的制作外观、造型、线条、材质、色板和光影原则。规则应具体到能检查画面，而不只是一串风格名称。

### 第二层：角色与场景资产

保存角色参考图、服装、配饰、比例，记录房间布局、主要道具及相互位置。风格一致不等于人物一致；同样的水彩提示词，仍可能生成不同的脸。

### 第三层：镜头画面与动态

画面描述负责机位、景别、构图和起始状态；动态描述负责人物动作、摄影机运动、先后关系和结束状态。需要尾帧时，再明确终点画面。

### 第四层：全片叙事、剪辑与声音

规定信息何时揭示、镜头如何连接、旁白怎样配合画面、音乐与环境声如何使用。这些内容多数应保留在分镜表或后期说明中，不需要全部塞进单镜头生成提示词。

| 设定层 | 主要产物 | 更新规则 |
|---|---|---|
| 全片视觉 | 风格卡＋代表性样图 | 定稿后稳定复用；变化时明确适用段落 |
| 资产 | 角色图、场景图、道具记录 | 同一身份保持关键特征，换装等变化需记录 |
| 镜头 | 首帧、可选尾帧、动作与运镜说明 | 每个镜头分别编写 |
| 全片视听 | 分镜顺序、旁白、剪辑点、声音表 | 随故事节奏调整 |

**统一的是规则，不是让所有镜头相同。** 白天与夜晚可以不同，远景与特写可以不同；它们应延续相同的美术语言与合理的时空关系。

## 3. 画风选项库：按维度选择

以下按实用检索整理，类别会有交集。不要把媒介、历史流派、用途和题材当成互斥选项。

### 3.1 媒介与技法外观

数字生成可以模拟这些外观，不代表实际使用了对应物理媒介。

| 选项 | 可见特征 | 描述时补充什么 |
|---|---|---|
| 铅笔素描 | 灰度、排线、擦抹 | 线条粗细、明暗密度、纸纹 |
| 炭笔 | 深黑、粗犷笔触、柔硬边缘 | 黑白比例、擦抹程度 |
| 钢笔／线描 | 轮廓和排线明确 | 是否填色、线密度、线宽 |
| 彩铅 | 细腻叠色、颗粒 | 色彩浓淡、笔触可见程度 |
| 水彩 | 透明色层、晕染、水痕 | 边缘软硬、留白、晕染范围 |
| 水粉 | 不透明色块、覆盖性 | 平涂或笔触、色块形状 |
| 油画 | 丰富色层、厚涂或罩染 | 笔触尺度、厚度、写实程度 |
| 丙烯 | 鲜明色彩、可平涂可厚涂 | 表面纹理、轮廓与覆盖方式 |
| 粉彩／油画棒 | 颗粒、摩擦、涂抹 | 颗粒粗细、叠色与边缘 |
| 马克笔 | 方向性笔触、清楚色面 | 是否保留线稿、色阶数量 |
| 水墨写意 | 墨色干湿浓淡、笔势、留白 | 墨块分布、人物细节程度 |
| 工笔 | 细勾线、层层设色 | 线条精细度、色彩与背景密度 |
| 木刻／版画感 | 刻痕、强轮廓、套色 | 刻线方向、用色数量、错版程度 |
| 拼贴 | 不同材料的边缘与叠层 | 纸张或照片来源类型、层次 |
| 喷绘／气笔 | 平滑渐变、柔边缘 | 亮面程度、色调与轮廓 |
| 数字厚涂 | 以笔刷塑造体积和光影 | 笔触显隐、材质、细节密度 |

### 3.2 造型与设计语言

| 选项 | 可见特征 | 注意 |
|---|---|---|
| 写实造型 | 接近自然比例和结构 | 写实造型也可以用水彩表现 |
| 卡通／Q版 | 简化形体、夸张比例 | 固定头身比与五官规则 |
| 日式漫画语言 | 漫画化造型，可使用网点、速度线 | 范围很广，需明确具体特征 |
| 美式超级英雄漫画 | 强动作、夸张体块、戏剧光影 | 不代表所有美式漫画 |
| 清线漫画 | 轮廓清楚、形状易读 | 明确背景与人物的细节关系 |
| 扁平插画 | 大色块、弱体积 | 约定是否允许渐变和投影 |
| 几何插画 | 基础几何形概括对象 | 固定形状和比例语言 |
| 等距插画 | 平行投影式空间表达 | 运镜时注意投影规则是否改变 |
| 涂鸦／童稚 | 不规则线条、稚拙比例 | 有意简化仍需要一致性 |
| 像素画 | 像素网格、有限色板 | 固定像素尺度，注意视频中网格漂移 |
| 低多边形 | 可见几何切面 | 固定面数观感与材质 |
| 黏土外观 | 圆润、手工压痕、可触摸感 | 黏土外观不等于实际定格制作 |
| 剪纸／纸雕 | 裁切轮廓、纸层与投影 | 固定层次和纸张厚度观感 |
| 复古印刷 | 网点、套色、油墨纹理 | 纹理过强会损失动作细节 |

“绘本”“编辑插画”“科学插图”主要指用途或创作领域，内部可有多种画风；“矢量”主要指图形表示方式，使用时仍要补充具体外观。

### 3.3 美术传统与审美参照

| 参照 | 可借用的视觉特征 |
|---|---|
| 古典主义 | 平衡、秩序、理想化比例 |
| 巴洛克 | 戏剧光影、动态构图 |
| 洛可可 | 轻盈色调、细腻装饰 |
| 浪漫主义 | 强情感、自然力量、宏大尺度 |
| 印象主义 | 光色变化、可见笔触 |
| 后印象主义 | 多种个人化探索；应进一步指定结构或色彩特点 |
| 野兽派 | 高饱和、非自然色彩 |
| 表现主义 | 变形、强色彩、心理化空间 |
| 立体主义 | 分解形体、多视角重组 |
| 超现实主义 | 梦境逻辑、不可能的组合 |
| 抽象艺术 | 色彩、线条和形状成为主要对象 |
| 极简主义 | 减少元素、强调比例与空间 |
| 波普艺术 | 大众符号、复制、鲜明色块 |
| 新艺术 | 植物曲线、流动轮廓 |
| 装饰艺术 | 几何、对称、放射与装饰秩序 |

这些是便于创作的特征摘要，不是完整的艺术史定义。流派名称最好作为参考方向，再转成可见描述。

### 3.4 世界观与视觉母题

| 标签 | 常见视觉线索 |
|---|---|
| 赛博朋克 | 高技术、社会失序、密集城市、身体改造 |
| 蒸汽朋克 | 蒸汽机械、黄铜、历史服饰改造 |
| 柴油朋克 | 工业机械、战争年代意象、厚重金属 |
| 太阳朋克 | 生态城市、植物与技术共存 |
| 废土／末日 | 破败设施、资源匮乏、生存装备 |
| 哥特 | 尖拱、幽暗空间、死亡与浪漫意象 |
| 东方奇幻 | 神话、传统建筑服饰、想象生物；应明确文化和时代参照 |
| 复古未来主义 | 过去时代对未来的想象 |
| Y2K | 千禧年前后的数码、透明塑料和亮面视觉 |
| 蒸汽波／合成器复古 | 怀旧数码或霓虹电子视觉；两者并非同一风格 |
| 梦核／怪核 | 熟悉空间中的异常、梦境或不安 |

母题需要具体设计支撑。“古风”不等于明确时代，“赛博朋克”也不等于只加霓虹灯。

## 4. 影视风格选项库：把时间与声音写出来

### 4.1 外观、制作方式与叙事载体

真人影像、二维动画、三维动画、定格动画、转描和混合媒介可以提供不同的视觉与运动参照。动态图形以文字与图形运动为主；屏幕叙事以界面为叙事载体；档案拼贴以已有材料组织内容。它们不属于完全相同的分类层级。

对于 AI 生成，应区分“看起来像定格动画”与“实际逐格拍摄”。提示词可以要求定格外观和节奏，但不能据此声称采用了真实定格工艺。

### 4.2 主要视听维度

| 维度 | 常用选项 | 应写成什么 |
|---|---|---|
| 景别 | 远景、全景、中景、近景、特写 | 主体与环境各占多少，强调哪部分 |
| 角度与构图 | 平视、俯视、仰视、对称、偏置 | 摄影机位置、人物朝向、留白方向 |
| 摄影机运动 | 固定、推近、拉远、横移、摇摄、跟随、手持 | 谁在移动、向哪里、速度怎样 |
| 空间与焦点 | 深焦、浅景深、焦点转移 | 哪个对象清楚，焦点是否变化 |
| 光线 | 自然光逻辑、高调、低调、柔光、硬光、明暗对照 | 光源位置、阴影、亮暗比例 |
| 色彩与质感 | 低饱和、高饱和、黑白、胶片、数码、家庭录像 | 色板、颗粒强度、清晰度 |
| 表演与动作 | 自然、克制、冷面、夸张、舞台化 | 视线、停顿、手势、身体变化 |
| 时间 | 实时、慢动作、延时、较长停留 | 动作速度与镜头持续方式 |
| 剪辑 | 连续、跳切、平行、匹配、联想、省略、分屏 | 哪里切、切到什么、建立何种联系 |
| 叙事 | 因果推进、生活流、诗意、非线性、群像、寓言 | 观众何时获得哪条信息 |
| 声音 | 环境声、配乐、旁白、主观声、声画对位 | 声音来源、进入时机、主次与停顿 |

“长镜头”指持续较长的连续镜头，不等于固定机位；“慢动作”改变动作呈现速度，不等于剪辑缓慢；“浅景深”也不是电影感的必备条件。

### 4.3 综合标签怎样落地

| 标签 | 可采用的一组手法，不是唯一公式 |
|---|---|
| 纪录片式 | 观察性机位、生活化表演、现场声、自然照明逻辑 |
| 黑色电影参照 | 强阴影、受限空间、道德困境、宿命性叙事 |
| 生活流 | 日常动作、较长停留、弱化戏剧强调、环境声 |
| 梦境式 | 时空跳跃、异常衔接、主观声音、非现实事件 |
| 时尚影像 | 造型与材质突出、身体表演、音乐组织段落 |
| 商业广告 | 产品可读、信息集中、受控灯光、明确节奏 |
| 史诗感 | 人与环境的尺度对比、群体调度、宏大叙事 |
| 民间志怪 | 日常生活与超常事件并置；可庄重、诙谐或悬疑 |

## 5. 怎样选出一套可执行风格

1. **先定观众体验。** 写一句话说明主情绪、转折和信息揭示方式。
2. **确定人物与场景的真实程度。** 写实、简化、夸张分别会影响情感和动作表达。
3. **选一种主导画面语言。** 再给辅助技法明确职责，如“木刻线条负责轮廓，水彩负责色层”。不必机械限制数量，但要避免相互竞争。
4. **固定色板与光影原则。** 可以区分日夜场景，不要把全片锁成完全相同的曝光和颜色。
5. **选动态基调。** 先确定动作密度、运镜方式、剪辑节奏、旁白与声音关系。
6. **测试代表性镜头。** 至少覆盖人物近景、场景全景和一个关键动作，再决定是否扩大制作。

测试时同时看美感和可动性：人物手部是否清楚，起始姿态是否方便完成动作，道具是否被遮挡，移动后需要补出的空间是否过多。

### 把模糊词转为可见要求

| 模糊词 | 一种可执行的具体化示例 |
|---|---|
| 电影感 | 侧面中景、前景轻遮挡、窗侧柔光、空间有层次 |
| 高级感 | 限定色板、材质统一、主体清楚、装饰克制 |
| 梦幻感 | 扩散光、柔边缘、缓慢运动、主观声音 |
| 紧张感 | 受限构图、动作停顿、逼近的声音、延迟揭示 |
| 古朴感 | 明确的器物与服装参照、低光泽材质、克制配色 |

上述示例不是这些感觉的唯一实现方法。

## 6. 三种生成路径，分别怎样写

### 6.1 单图生视频

**生图输入：全片视觉规则＋角色／场景参考＋本镜头起始画面。**

**视频输入：已确认的图片＋主要动作＋运镜＋结束状态＋必要的一致性要求。**

图片已经提供的内容，无需逐项重复；但当关键材质或身份容易漂移时，可以简短强调。不要用与输入图竞争的大段新美术描述。

示例：

```text
延续输入图的二维淡彩水墨外观、人物服装和侧面光线。
摄影机固定。女孩先停下阅读，随后轻轻抬头看向右侧窗外，
最后保持凝望。双手留在书旁，窗上雨滴缓慢滑落。
```

### 6.2 首尾帧视频

**首帧与尾帧共享身份、场景和视觉规则；分别说明起点与终点，再描述中间发生的动作。**

尾帧优先通过首帧编辑或参考图约束生成。摄影机固定时，家具、背景与构图应相互匹配；摄影机移动时，两帧必须允许合理的透视与遮挡变化。

```text
首帧：女孩低头看书，右手放在书旁。
尾帧：女孩仍坐原位，双手未移动，头部转向右侧窗外。
过渡：先抬起视线，再轻轻转头，最后停留。摄影机固定。
```

首尾帧约束的是端点，不能保证中间路径、动作次序或物体接触正确。洗脸、递物、换手等复杂动作宜拆分；跨场景变化通常采用多个镜头或明确的转场设计。

### 6.3 文生视频

**输入：全片视觉规则＋角色与场景＋起始构图＋动作过程＋运镜＋结束状态。**

没有输入图提供视觉锚点，因此要写清关键外观。先描述一个连贯镜头；多镜头叙事留在分镜表中，或在支持相关控制的工具中明确组织。

```text
二维水彩动画，细铅笔线条，灰蓝与米白色板，柔和窗光。
黑色短发女孩穿米白开衫，坐在旧书店窗边，侧面中景，
人物居左，右侧玻璃窗上有雨滴，打开的书放在面前。
摄影机固定。女孩从低头阅读到轻轻转头看窗外，最后停留。
```

具体输入数量、首尾帧支持、时长、参考图、种子及声音功能，以实际工具界面或文档为准。本文不假设所有工具都有这些能力。

### 哪些内容应放在哪里

| 信息 | 生图 | 单镜头视频 | 分镜／后期 |
|---|---|---|---|
| 造型、材质、色板 | 详细 | 简短延续；文生视频需写清 | 记录统一规则 |
| 起始构图与姿态 | 详细 | 以图为起点或用文字写清 | 检查前后衔接 |
| 人物动作与运镜 | 只准备适合动作的状态 | 重点描述 | 检查节奏 |
| 尾帧 | 按需生成 | 用于终点约束 | 检查下镜起点 |
| 多镜头顺序与切点 | 不用描述整段故事 | 单镜头通常不承担 | 重点描述 |
| 旁白与音乐 | 不用 | 支持音频时按能力描述 | 配音、剪辑、混音 |

## 8. 实例：《张天师收服水鬼》

以下依据用户提供的故事梗概设计，不代表对其所引原书版本的独立核验。人物面貌、颜色和场景细节属于改编设定。

### 8.1 先确定故事体验

**普通家庭接纳了一个勤快孩子；洗脸让束缚解除，最后才揭晓其水鬼身份。** 前段保留生活气息，关键异常短暂而明确。孩子不宜过早呈现典型怪物特征，否则结尾的信息揭示会减弱。

故事顺序保留：首年春夜役鬼熄灯 → 次日答应赠徒 → 次年送来孩子并叮嘱不可洗脸 → 孩子帮工 → 妻子洗脸 → 道谢消失 → 天师说明身份。

### 8.2 全片风格卡

| 项目 | 设定 |
|---|---|
| 画面形式 | 二维民间志怪绘本外观 |
| 主辅技法 | 木刻感轮廓负责形体，淡彩水墨负责色层，轻微纸纹负责底材 |
| 人物 | 自然比例、简洁五官；张天师从容，举人夫妇生活化，孩子外观近似常人 |
| 色板 | 米黄、墨黑、灰青、木褐；朱红集中用于额头印记 |
| 日夜光线 | 白天柔和阴天光；夜晚局部暖黄油灯光，暗部仍保留可读轮廓 |
| 场景 | 南方旧宅、木窗、书案、天井、石板地；具体时代未明，避免标注为史实复原 |
| 动态 | 固定机位为主，关键细节少量推近，表演克制 |
| 叙述 | 第三人称旁白，画面呈现关键动作与反应 |
| 声音 | 雨滴、脚步、扫地、倒水、拧布声；揭晓前适当留白 |

朱印样式需设计后固定。原梗概仅提到头上印记，未给出具体图案；将其设计在额头是便于叙事的改编选择。

### 8.3 共用生图描述

```text
二维中国民间志怪绘本插画，木刻感轮廓线勾勒人物和建筑，
内部用淡彩水墨铺染，保留轻微旧宣纸纹理。人物比例自然，
五官简洁，轮廓清楚。米黄、墨黑、灰青和木褐为主要颜色，
朱红集中用于关键印记。南方旧宅的木质家具和石板地，
材质朴素，整体安静古朴。光线按当前日夜场景设置。
```

在实际提示词中，将最后一句替换为本镜头具体的光源与亮暗关系；同时附上已确认角色和场景参考。

### 8.4 分镜与生成方式

| 镜头 | 画面／信息 | 动态与制作选择 |
|---|---|---|
| 01 春夜借宿 | 天师在灯下，举人在门外看见 | 单图生视频；固定中景、灯火微动 |
| 02 役鬼熄灯 | 手指划动、暗处异样轮廓、灯灭 | 拆成手势与灯火两个短镜头；可用亮灯／灭灯首尾帧 |
| 03 次日询问 | 举人惊疑，天师从容答应 | 单图生视频；轻微表情，旁白承担对白信息 |
| 04 次年赠童 | 孩子在天师身侧，朱印可辨 | 稳定中景；用旁白明确时间跳跃及不可洗脸的叮嘱 |
| 05 日常帮工 | 扫院、端茶、整理物件 | 分别生成短镜头；每镜一个主要动作 |
| 06 准备洗脸 | 妻子看到脏脸，拿起湿布 | 单图生视频；明确手、布、脸的相对位置 |
| 07 印记消失 | 湿布擦额头，朱印不再可见 | 拆成接触与擦净结果；首尾帧可辅助，仍需检查中间动作 |
| 08 道谢离去 | 孩子道谢，随后原处空了 | 孩子画面→妻子反应→空位，用后期剪辑完成 |
| 09 真相揭晓 | 天师出现并说明，夫妇惊惧 | 旁白与反应镜头；最后短暂停留 |

“鬼”不必一律化烟、发光或变形。消失可以由镜头连接表达，避免把叙事效果完全交给复杂生成特效。

### 8.5 洗脸镜头的首尾帧示范

```text
【首帧】
沿用角色与屋内场景参考。侧面近景，孩子站在左侧，妻子在右侧。
孩子额头朱印清楚，妻子右手拿湿布，停在额头旁；左手自然垂下。
两人身体与背景位置固定，日间柔光从左侧窗户照入。

【尾帧】
基于首帧编辑。保持同一人物、机位、背景和光线。
湿布已离开额头，妻子右手略微下落，孩子额头干净，朱印消失。
孩子仍然站在原位，准备抬眼。

【过渡动态】
摄影机固定。妻子用右手湿布轻轻擦过孩子额头，随后收回手。
孩子身体不动。动作缓慢连贯，保持二维线条与水墨色层。

【检查／替代】
检查湿布是否真实接触额头、手指是否变形、朱印是否在擦拭后消失。
若中间过程不自然，改用局部接触镜头与擦净结果镜头连接。
```

道谢和消失放在后续镜头，不把洗脸、印记消退、说话、消失同时压进一个生成片段。

## 9. 一致性检查与常见问题

| 检查项 | 具体看什么 | 出问题优先怎么改 |
|---|---|---|
| 美术 | 线条、表面、色板、细节密度 | 减少冲突描述，回到已确认样图 |
| 身份 | 脸型、发型、比例、服装和标志 | 补充一致的角色参考，修正关键帧 |
| 空间 | 门窗、桌椅、杯子、左右方向 | 对照场景布局，修正起始图或尾帧 |
| 光线 | 光源位置、日夜、色温 | 明确当前场景光线和变化原因 |
| 动作 | 接触、重心、手部、动作次序 | 减少同步动作，拆成可读的短镜头 |
| 运镜 | 人在动还是摄影机在动 | 分别描述主体与摄影机，不只写“缓慢移动” |
| 连续性 | 上镜结束与下镜开始是否接得上 | 调整姿态、视线、道具状态或插入过渡镜头 |
| 叙事 | 是否提前泄露信息、遗漏关键因果 | 调整镜头顺序和旁白 |
| 声音 | 是否抢旁白、是否与动作同步 | 在后期调整进入时间、音量和留白 |

重复风格词只能帮助约束，不能保证一致；“保持不变”也不是硬锁定。参考图、关键帧检查与后期修整需要共同使用。若工具提供种子或参考权重，可以记录用于复现和比较，但它们也不能单独保证跨镜头身份一致。

先修影响叙事、身份和空间的错误，再优化小纹理。某个动作连续失败时，优先改变镜头拆法或使用剪辑表达，不必一味增加提示词长度。

## 10. 对原总结的评估与使用边界

原总结的优势是分类有条理，已提出全片视觉、单镜头画面、单镜头动态的分工，并包含三种生成路径。作为入门资料有用，作为直接执行的规范仍需补充约束和例子。

| 原总结表述／做法 | 问题 | 本手册的处理 |
|---|---|---|
| “权威定义” | 未给出权威来源 | 明确为实用创作框架 |
| “二者正交” | 忽略色彩、光线、构图等交集 | 采用共享视觉规则与时间性视听扩展 |
| “各自都不混搭” | 过于绝对，也与后文可混合矛盾 | 允许有主次、有范围的组合 |
| “画风＝三个维度” | 缺少造型、材质、色板等执行字段 | 将分类词库与生产设定分开 |
| 将不同层级并列 | 媒介、用途、叙事载体混在一起 | 标明类别交叉和用途边界 |
| skill 覆盖表直接打勾／判盲区 | 当前仅阅读该总结，未核验所指 skill | 删除确定性覆盖结论；需要时另做文件级审查 |
| 复制风格词“只能统一第 1 项” | 对结果承诺过强 | 改为帮助约束，仍需参考与检查 |
| 三种路径只有简短提纲 | 缺少首尾状态、动作路径和后期职责 | 补充输入分工、模板和完整案例 |
