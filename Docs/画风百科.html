影视与动漫画风百科

用途：做 AI 漫剧/短视频时挑选统一画面风格（光影、色调、笔触、构图）的速查手册。

核心原则：做视频，画面风格必须全片统一，禁止混搭——除非显式插入"风格段落标记"（如 MV、回忆、梦境、戏中戏），主叙事全程同一视觉系统。

一、影视画风

A. 商业大片/电影级

cinematic 电影感通用底色

浅景深、宽幅 anamorphic 镜头光晕、暖冷对比、低饱和。

通用兜底

诺兰/扎克施耐德写实质感

冷青绿、暗部死黑、强剪影。

代表作：黑暗骑士、敦刻尔克、正义联盟

韦斯安德森对称构图

高饱和糖果色、置景戏剧化、强迫症构图。

代表作：布达佩斯大饭店、月升王国

雷德利斯科特史诗

沙黄+铜绿+颗粒胶片。

代表作：角斗士、天国王朝

罗杰迪金斯自然光

远景氤氲、近景锐利、阴影叙事。

代表作：边境杀手、银翼杀手 2049

库布里克凝视构图

代表作：闪灵、发条橙

三、中国特色画风

A. 传统国画五大类

水墨写意

齐白石、徐渭泼墨；留白、墨分五色（焦浓重淡清）。

适配：道家、隐士、山水

工笔重彩

宋代院体、永乐宫壁画；线条精谨、金碧勾填。

适配：宫廷、仕女、神祇

青绿山水/金碧山水

王希孟千里江山图；石青+石绿+泥金。

适配：仙山、仙境

浅绛山水

黄公望富春山居图；赭石为主+淡彩。

适配：文人山水、隐逸

白描/没骨

连环画（小人书三国演义）、恽寿平没骨花卉。

B. 古代壁画与石刻

敦煌壁画

飞天、反弹琵琶、九色鹿；朱红+石青+佛青+描金。东方写意+宗教庄严。

永乐宫壁画

元代道教神仙；线条遒劲、色彩浓烈。

汉画像石/砖

剪影感、平面化、汉代神话。

适配：汉代题材、祠堂

杨柳青（工笔重彩）、桃花坞（江南雅致）、朱仙镇（粗犷木版）、绵竹（四川）。

皮影戏

陕西/唐山/陇西；镂空剪影+光影投射。

剪纸

陕北/河北；阴阳刻、图案化。

刺绣/织锦

苏绣湘绣、云锦蜀锦（图案化、几何对称）。

蜡染/扎染

贵州蓝白。

泥塑/面塑

无锡惠山泥人、浚县泥咕咕。

国漫网络动画

F. 东方美学底层规律（可直接写进 prompt）

  1. 留白——画面大量空，气在画外
  2. 散点透视——长卷多点视线
  3. 大气透视——远山朦胧，明度暗→亮、对比高→低、暖→冷、繁→简
  4. 墨分五色——焦浓重淡清
  5. 朱红+石青+石绿+泥金——皇家/仙凡配色公式
  6. 虚实相生——雾、雨、雪、月作为情绪载体

五、视觉统一性铁律

  1. 一部作品只选一套主视觉系统，从片头到片尾贯穿。
  2. 唯一允许"换画风"的场景：MV 段落、回忆杀、梦境、戏曲嵌套、戏中戏——这些必须有显式转场标记。
  3. 同一部作品的 prompt 风格块（positive 关键词）必须严格复用，只允许在 style_override 列做单镜微调（光影、构图、镜头焦段）。
  4. 角色必须全片同一张脸/同一套服装/同一套装备——靠项目级 characters.json 锚定，不能每镜重新描述。
  5. 色彩取样：主色不超过 3 个 + 1 个强调色，整套画面围绕这 3+1 跑；不要每镜换调。
  6. 光源逻辑：全片光向一致（左前 45° 或顶光），不要有的镜次顶光有的顺光。
  7. 笔触/颗粒/纸张/胶片：选一种质感到底（水墨纸纹 OR 胶片颗粒 OR 数字锐利），不要混。

六、003 项目选画风建议

题材核心：道教 + 民俗 + 斗法 + 民俗惊悚

候选优点风险建议
新中式国漫电影 模型训练样本多、出图稳定、人物造型清晰 易同质化（哪吒味） ★ 首选
工笔重彩 + 敦煌 庄严感最强、符箓发光契合 生图模型对工笔线稿训练少，易糊 备选，需大量 negative 调校
纯水墨写意 东方意境最足 留白过多会稀释紧张感（S07/S11 已踩坑） × 已弃用
皮影戏 视觉钩子强、辨识度极高 不适合人物近景（看不清脸） 仅做战斗剪影穿插
最终建议：003 主画风 = 新中式国漫电影（哪吒/白蛇风），全片统一，不混搭。
