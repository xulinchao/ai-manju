〇、一句话正名

画风

一张画面看起来是什么样 —— 决定静态视觉（笔触/色彩/构图/线条）。

影视风格

画面怎样变化、故事怎样展开、声音怎样参与 —— 决定动态视听（镜头/剪辑/叙事/声音/表演）。

「水彩」是一种画风，但「水彩动画」可以是温柔日常、悬疑故事、快节奏广告——同一种画风，能承载不同影视风格。

2. 美术流派 / 审美传统（遵循什么审美原则）

写实主义超写实古典主义巴洛克洛可可浪漫主义印象主义后印象主义野兽派表现主义立体主义超现实主义抽象艺术极简主义波普艺术新艺术装饰艺术

可混合：如「表现主义人物 + 数字厚涂」不矛盾——前者是审美，后者是技法。

四、你现有 skill 的覆盖盲区

层级该管的事你的 skill覆盖
画风·媒介技法用什么画无❌ 盲区
画风·美术流派什么审美无❌ 盲区
画风·视觉母题什么世界观无❌ 盲区
影视·制作形式怎么拍无（默认生图）⚠️ 半覆盖
影视·摄影机位运镜CINEDANCE✅
影视·灯光色彩光调Lira（间接）⚠️ 半覆盖
影视·叙事导演怎么讲CINEDANCE✅
影视·剪辑节奏怎么切CINEDANCE（节拍）⚠️ 半覆盖
影视·表演怎么演ACTING 7✅
影视·声音声音设计无❌ 盲区
结论：✅ 已覆盖 = 调度三件套（摄影/叙事/表演）；❌ 盲区 = 画风三件套（媒介/流派/母题）+ 声音。
画风「难定」是结构性的——体系里没有任何环节负责它。解法不是再学画风，而是把画风变成「显式的一层设定 + 有约束的决策流程」（见 style-decider skill）。

五、三层结构：统一视觉的落地方法

层级写什么用在哪
全片视觉设定画法、角色造型、材质、色彩、光线、时代环境所有图+视频共用
单镜头画面设定人物、场景、景别、构图、姿态、道具位置首帧/尾帧/生图
单镜头动态设定动作过程、镜头运动、速度、先后、结束态图生视频/首尾帧/文生视频
全片设定管「始终长什么样」；画面设定管「这一刻」；动态设定管「接下来怎么变」。

六、模糊词 → 可见特征 拆解表

模糊描述更容易执行的描述

七、真正要统一的五项（不止风格词）

  1. 画面风格：线条、材质、细节程度、色板
  2. 角色身份：脸型、发型、体型、服装、标志配饰
  3. 场景空间：门窗方向、家具位置、道具关系
  4. 光线逻辑：光从哪来、时间、天气、曝光、色温
  5. 动作连续性：上镜结束姿态能否接上下镜
只复制「水彩动画风」只能统一第 1 项；其余 4 项靠参考图、场景设定、镜头衔接。视觉统一 ≠ 每镜完全一样——景别/角度/构图可变，但人物身份、美术规则、空间关系必须对得上。
