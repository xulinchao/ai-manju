# AI 视频人物与场景一致性制作方案

> 适用：先生成图片再制作故事视频、首尾帧视频，以及需要重复使用人物和场景的系列内容。整理日期：2026-09-12。

**推荐流程：角色与场景资产库 → 参考图生成分镜 → 关键帧审核 → 短镜头图生视频 → 后期修正。**

这是一套基于现有工具能力整理的生产建议，不是对某个模型的效果保证。纯生成不能承诺人物与场景始终完全一致；要求严格固定的部分，应采用二维分层、三维资产或后期合成。

## 1. 一致性需要分开解决

| 对象 | 常见问题 | 主要手段 |
|---|---|---|
| 人物身份 | 换脸、发型变化、服装纹样变化、身高比例变化 | 角色主参考、多角度资产、局部编辑 |
| 场景空间 | 门窗换位置、家具增减、反打时房间变化 | 布局图、固定机位底图、必要时三维场景 |
| 镜头内连续性 | 转头后变脸、道具消失、背景变形 | 合格首帧、简化动作、关键帧控制、过程检查 |
| 跨镜头衔接 | 视线、手势、道具状态和光线接不上 | 镜头状态记录、相邻画面对照、剪辑调整 |

角色像同一个人，与房间确实是同一个空间，是不同要求。“保持一致”可以作为提示，但不能替代参考资产和检查。

## 2. 第一步：角色定稿与资产建立

每个主要角色从以下资产开始，按实际镜头补充，不必一次做全：

- 清楚的脸部正面图。
- 四分之三侧面图，必要时补侧面和背面。
- 全身服装图，明确身高比例、鞋子和配饰。
- 关键印记、纹样或道具细节。
- 一段简短的固定特征说明。

**先选定一张主参考，再由它派生其他角度并逐张审核。** 分别独立生成正面、侧面和背面，可能得到三个相似但不同的人。尚未审核的新角度不能直接升格为标准参考。

角色总览图用于人工查看；实际生成时按镜头选择清楚的单张参考，避免多格图中的面部过小。侧面镜头优先选用已核准的侧面参考。

资产说明区分固定项与状态变化：脸型、基本比例是身份特征；换装、污渍、额头印记等按剧情记录。不要把剧情中应该改变的内容一律锁死。

Runway 官方参考图指南说明了通过参考图生成不同环境下角色的方法，并建议中性表情、均匀照明等参考条件。该能力仍需要结果审核。[官方参考图指南](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)

## 3. 第二步：场景布局与固定机位底图

为重要场景建立“布局＋主图＋实际用到的机位图”。布局可以是简单手绘，不要求复杂建模。

示例：门在南侧，窗在东侧，书案靠窗，书架靠北墙，油灯放在书案左后方。

这里使用房间的固定方位。不要只写“窗在画面左边”，因为摄影机换向后，窗在画面中的位置可以合理改变。

| 场景资产 | 用途 |
|---|---|
| 俯视布局图 | 确认门窗、家具和人物位置 |
| 无人物主图 | 确认美术、布置与材质 |
| 机位 A：全景 | 空间交代、人物入场 |
| 机位 B：书案方向 | 施法、询问、动作主体 |
| 机位 C：门口方向 | 反应、进出、反打 |

**同一机位尽量复用同一底图，再编辑人物和道具。** 编辑工具仍可能改变背景，输出后需比较。必须精确保留时，将背景作为独立图层，在后期合成人物。

参考图生成的多个角度不自动构成正确的三维空间。需要复杂反打、环绕或长距离运镜时，可用三维布局提供位置、透视和遮挡依据。三维渲染之后若再进行生成式处理，也要检查几何是否被改动。

## 4. 第三步：先完成静态分镜并审核

每个镜头使用：**角色参考＋指定机位场景图＋本镜头姿态与构图。**

```text
使用角色参考中的张天师，保留脸型、发髻和道袍。
以书房机位 B 为场景依据，保留门窗、书案和油灯布局。
张天师坐在书案后，右手抬到灯旁，侧面中景。
光线延续该夜景机位的油灯照明。
```

参考图需明确职责：哪张负责人物、哪张负责房间、哪张负责动作。不要把互相冲突的图片全部投入模型，再期望它自行取舍。

多参考图编辑可用于角色、衣物、家具和环境组合。例如 FLUX.2 的官方指南列有角色一致性与室内组合应用。具体参考数量和参数以实际工具为准。[官方多参考图说明](https://docs.bfl.ai/guides/prompting_guide_flux2)

把整组分镜排在一起，检查脸、衣服、比例、家具、光线与道具。发现错误先修静帧，再生成视频。单张好看不能替代整组连贯。

## 5. 第四步：视频增加必要的运动

视频提示词重点描述：**谁做什么 → 动作顺序 → 摄影机怎么动 → 最后停在哪里。**

```text
延续输入图的二维水墨外观、人物服装与油灯光线。
摄影机固定。张天师右手食指在油灯旁轻轻划过，随后收回。
身体基本不动，衣袖随手臂轻微摆动。
```

- 一个短镜头承担一个主要动作，时长由动作与工具能力决定。
- 手部接触、多人交互、遮挡和转身分别测试。
- 主体运动与摄影机运动分开写。
- 动作持续失败时，调整拆镜方式或改用后期表达。
- 首尾帧约束端点，仍需检查中间的动作路径、接触和身份变化。

Veo 提供首尾帧输入功能，但功能支持不应被理解为对所有中间动作的硬性锁定。[官方首尾帧说明](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/video/generate-videos-from-first-and-last-frames)

## 6. 第五步：有限接力，持续回查主参考

上一个镜头的合格尾帧，可以辅助下一个连续镜头；不能不经审核无限接力。某一镜已经发生的细微变脸或场景漂移，可能被后续镜头继承。

每个新镜头都回查角色主参考和场景底图。只有审核通过的输出，才能成为后续参考。跳时间、换机位或换场景时，根据新的镜头需求重新调用标准资产。

固定模型版本、记录参考图和参数有助于比较结果；种子不能单独锁定身份。局部问题优先局部编辑，避免无谓重生成整个画面。

## 7. 三类制作方案如何选择

| 方案 | 组成 | 适用 | 限制 |
|---|---|---|---|
| 参考图流程，当前首选 | 角色／场景参考、多图编辑、静态分镜、图生视频 | 民间故事、绘本短片、一般叙事 | 仍需挑选、审核和修图 |
| 结构控制流程 | 参考图＋姿态／深度／轮廓约束＋局部重绘 | 姿势构图明确、持续批量制作 | 配置较复杂，要确认兼容性 |
| 二维／三维资产混合 | 固定背景、分层角色或三维场景＋动画＋局部生成 | 精确空间、反复使用角色、多反打与运镜 | 前期资产成本更高 |

在结构控制流程中，IP-Adapter 提供图像参考，ControlNet 可通过深度、边缘或姿态约束结构。两者职责不同，不能自动锁定全部内容。[Diffusers 官方说明](https://huggingface.co/docs/diffusers/using-diffusers/ip_adapter)

对固定机位、局部动作的水墨绘本，二维分层值得优先考虑：背景、人物、前景遮挡分别保存；可以直接控制的移动用动画，复杂表演再用生成。直接复用背景层时，其内容无需反复由模型重画。

本方案不要求一开始训练专用模型。先用代表性镜头判断参考图流程是否满足要求，再决定是否增加更复杂的技术环节。

## 8. 《张天师收服水鬼》的资产与制作安排

依据用户提供的故事梗概。造型和场景细节属于改编设计，不作为历史复原结论。

### 主要资产

| 类别 | 内容 |
|---|---|
| 角色 | 张天师、举人、妻子、水鬼小孩 |
| 次要形象 | 首年熄灯的怪物，按镜头需求确定局部轮廓即可 |
| 场景 | 书房、庭院、洗脸位置及实际使用机位 |
| 道具 | 油灯、水盆、湿布、额头印记 |
| 小孩状态 | 有印记；洗净后无印记；离去后空位 |

额头印记是将原梗概“头上印记”具体化的美术选择，样式确认后固定。空位属于镜头／场景状态，不是新角色。

### 制作顺序

角色定稿 → 场景布局与机位图 → 全部分镜静帧 → 一致性审核 → 分镜视频 → 剪辑与声音。

| 关键效果 | 建议处理 |
|---|---|
| 灯熄灭 | 固定背景，控制灯火和局部亮度变化；照明改变时相应调整受光区域 |
| 印记洗掉 | 分成擦拭与擦净结果，检查手、湿布和额头接触 |
| 孩子消失 | 孩子画面 → 妻子反应 → 同机位空背景，用剪辑完成 |

保留关键因果：天师叮嘱不可洗脸 → 妻子看到脸脏 → 洗掉印记 → 孩子道谢消失 → 身份揭晓。不要让一段复杂生成承担全部事件。

## 9. 可复用的镜头记录与验收

```text
【镜头记录】
镜头编号：
叙事作用：
生成方式：
角色主参考与版本：
当前服装／印记／道具状态：
场景与机位参考：
首帧文件：
尾帧文件（按需）：
主要动作与结束状态：
摄影机运动：
模型版本与相关参数：
合格输出：
尚待修正：
```

| 验收项 | 合格判断 |
|---|---|
| 人物 | 脸型、发型、体型、服装和关键配饰与参考相符 |
| 空间 | 门窗、家具、人物位置及遮挡关系合理 |
| 道具 | 数量、位置、手持关系与剧情状态相符 |
| 动作 | 无影响观看的形变，接触与动作次序可读 |
| 光线 | 来源合理，同场景相邻镜头能衔接 |
| 画风 | 线条、色板和材质与全片规则协调 |
| 叙事 | 信息没有遗漏或提前泄露，动作结果明确 |

审核静帧后，还要查看视频的开始、中间、结束及关键接触时刻。单看首尾不能发现所有动态问题。

## 10. 接入工作目录时的落地方式

工作目录打开后，先阅读已有项目说明、角色、场景、分镜和工具流程，再决定如何接入。优先沿用已有命名和资产，不预先假设缺少哪个 skill，也不覆盖已有内容。

可以参考以下最小组织结构；若项目已有结构，做对应映射即可：

```text
项目/
  设定/       全片风格、角色说明、场景布局
  参考资产/   已核准角色、场景机位、道具
  分镜/       镜头记录、首帧、尾帧
  视频/       候选片段、已选片段
  交付/       成片与最终文档
```

候选图与已核准参考应能明确区分。后续最先落实的是角色主参考、场景机位底图和代表性镜头验证，再扩大生成规模。
